# Sample STEP files

Generated by `src/tools/make_samples.py` (re-run: `freecad.cmd -c "exec(open('src/tools/make_samples.py').read())"`).
Each case has a part (`*_part.step`, moved and turned away from the assembly) and an assembly (`*_assembly.step`, several separate solids including decoys).
`samples.json` holds the same face ids and expected results. `Redraw.step` is the lathe from the assignment (22 MB, not tracked).

Run: `.venv/bin/python src/search/match.py stepfile/<case>_part.step <faces> stepfile/<case>_assembly.step`
